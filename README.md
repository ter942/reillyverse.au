# reillyverse.au

Welcome to **reillyverse.au** — the personal portfolio and homepage of Tom Reilly, an experienced Systems Administrator based in Australia. This website showcases my work, projects, and passion for technology.

## 🚀 About the Project

reillyverse.au is a static website built to highlight:
- My professional experience and technical skills.
- Selected IT projects I have delivered or supported.
- My interest in automation, infrastructure, and clean design.

## ⚙️ Technology Stack

- **Hugo** — fast, flexible static site generator.
- **Netlify** — modern platform for automating deployment and hosting.
- **Markdown** — for content writing and structure.
- **GitHub** — version control and collaboration.

## 🌐 Live Site

👉 [https://reillyverse.au](https://reillyverse.au)

## 🛠 Deployment

This site is automatically deployed from this repository using Netlify’s CI/CD pipeline. Any changes pushed to the `main` branch trigger a build and deploy to production.

## 📂 Structure

- `content/` — markdown content files.
- `static/` — images and static assets.
- `themes/` — site theme (Hugo-Scroll).
- `config.toml` — site configuration.

## ✨ Features

- Single-page scroll layout with Hugo-Scroll theme.
- Responsive design for mobile and desktop.
- Simple, fast-loading static content.
- Easy to maintain and extend.
